# Running2 구현 계획서 독립 QA

검토일: 2026-10-08  
대상: `plan/running2-implementation-plan.md`

## 최초 검토

### PASS

- 지도와 측정 거리를 같은 세그먼트에서 계산하도록 정의함.
- 정지 잡음, GPS 공백, 수동 일시정지의 거리·시간 처리를 구별함.
- 3km 실측과 반환점·공백·화면 꺼짐 시험 기준이 있음.

### ISSUES 및 반영

1. 첫 3km 시험을 조정과 최종 검증에 함께 사용할 위험 → 첫 구현, 첫 실측, 조정, 별도 재실측 순서 명시.
2. 원본 보존과 중복·역전 시각 제거 문구 충돌 → 원본 전량 저장, 엔진 입력에서만 제외하도록 수정.
3. 주기적 저장 시 마지막 버퍼 손실 위험 → 위치 콜백 배치를 먼저 영속화한 뒤 처리하도록 수정.
4. 비정상 종료 시 기록 종료 시점 불명확 → 마지막 영속 관측 또는 상태 이벤트 시점으로 확정.
5. 정지 상태와 GPS 품질 불량의 측정 구간 시간 차이 불명확 → 정지 상태는 시간 포함, 품질 불량은 제외하도록 명시.

## 재검증

- 5개 항목 모두 반영 확인.
- 남은 High/Medium 이슈 없음.
- 구현 전이므로 빌드, 저장·복구 동작, 실기기 GPS 정확도는 미검증.
